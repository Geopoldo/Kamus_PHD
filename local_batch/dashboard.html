MAP-H / Laboratorio documental

De una imagen a información que podemos consultar.

● Inferencia 100% local

Piensa en un lector automático: abre cada PDF, mira sus páginas y escribe lo que alcanza a leer. No basta con que termine: nombres, fechas y manuscritos todavía necesitan revisión.

01 / Inventariar

Contamos PDF y páginas por carpeta. Una huella identifica cada archivo para conservar sus resultados.

02 / Preparar

Poppler convierte una página PDF en PNG de hasta 3000 píxeles de lado mayor. Si tiene dos escaneos, ambos se conservan juntos.

03 / Leer

Qwen recibe la imagen y una instrucción. La GPU calcula la respuesta: una sola página por turno, sin enviar el documento a un proveedor externo.

04 / Guardar

Conservamos texto Markdown, respuesta JSON y tiempos por página. Los originales se mantienen separados de los resultados.

05 / Vigilar

Medimos memoria y GPU cada tres segundos. Reintentamos una vez los errores técnicos y señalamos respuestas vacías, truncadas o repetitivas.

06 / Revisar

«Completada» significa que la ejecución acabó. La validación humana se registra por separado; el sistema no certifica automáticamente la exactitud.

¿Qué tecnología y equipo hacen el trabajo?

El lector: Qwen3.5-9B

Modelo de visión y lenguaje que interpreta una imagen y genera texto. Usamos la versión GGUF Q4_K_M: sus pesos están comprimidos para reducir la memoria necesaria.

Motor: llama.cpp con CUDA. El ejecutable está instalado por LM Studio, pero este lote usa directamente llama-server; no la interfaz de LM Studio ni Ollama.

El equipo: este portátil

GPU: NVIDIA GeForce RTX 5080 Laptop, 16.303 MiB de memoria de vídeo, aproximadamente 16 GB.

CPU: Intel Core Ultra 9 275HX, 24 núcleos.
RAM: aproximadamente 30 GiB reconocidos por el sistema.

La CPU prepara archivos; la GPU ejecuta las capas del modelo. La memoria de vídeo guarda los pesos y el trabajo temporal.

El coordinador y el panel

Python recorre carpetas, guarda resultados y coordina el modelo. Poppler prepara las imágenes. Este dashboard usa HTML, CSS y JavaScript locales, sin librerías ni fuentes descargadas al abrirlo.

El panel consulta metadatos cada cinco segundos. Las curvas muestran recursos; no muestran el contenido de las páginas.

Los límites del lector

Contexto: 8192 tokens; presupuesto visual: hasta 4096; salida: máximo 4096. Un token es una pequeña unidad de texto o representación interna, no una página.

Temperatura 0 y semilla 42 reducen variación; no garantizan que la lectura sea correcta. Un documento denso puede llegar al límite antes de terminar.

¿Qué le pedimos exactamente al modelo? Ver el prompt real

En este lote hay un único prompt de transcripción, repetido con cada imagen. Este texto se muestra desde la configuración guardada de la ejecución:

{{MODEL_PROMPT}}

En español, para entender la instrucción

«Transcribe todo el texto visible de esta imagen histórica en orden de lectura. Conserva la ortografía inglesa original, nombres, fechas y párrafos. No resumas, traduzcas, modernices ni completes texto fuera de la imagen. Marca las palabras realmente ilegibles como [illegible]. Devuelve sólo la transcripción».

Esta traducción es explicativa; el modelo recibe el texto en inglés de arriba. No recibe la referencia Astra, el Excel de nombres esperados ni instrucciones para completar información que no aparece.

¿Qué significan las métricas y hasta dónde llega este ejercicio?

Avance y tiempo global

La estimación suma TODAS las páginas PDF pendientes del lote. Combina la media general con las últimas 30 páginas. Los filtros sólo cambian la tabla y la gráfica de páginas: no reducen el alcance de la estimación.

El rango es orientativo y supone trabajo continuo. No incluye revisión humana. Una página PDF puede contener varios escaneos, todavía sin segmentar ni contar individualmente.

Velocidad y capacidad

Render es preparar la imagen; inferencia es el tiempo del modelo; total es el tiempo de pared, incluidos reintentos. Tokens indican cuánto texto generó, no cuántas palabras leyó bien.

GPU indica actividad; VRAM es memoria de la tarjeta; RAM disponible es el margen del sistema. Ninguna de estas métricas mide exactitud. Para escalar debemos comprobar también calidad, páginas difíciles, errores y almacenamiento.

Fuera de alcance de esta pasada: revisión humana, corrección validada de nombres, extracción estructurada contra el Excel, identificación fiable de tachados y separación automática de páginas dobles. Una marca de revisión puede ser un falso aviso y una lectura errónea puede pasar sin aviso.
